A program that writes one invented word and its one-line definition to `/output/entry.txt`: "backwave (n.): waving back at someone who was waving at the person behind you." (78 characters, inside the 140-character cap.) English has no word for that moment — everyone has felt it, nobody has named it — and "backwave" is built from plain English parts, so it is sayable, spellable and memorable at once.

## Run it

```sh
python3 main.py
```
